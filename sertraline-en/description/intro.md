# Intro

Welcome to Sertraline's realm!

Download Sertraline from [Modrinth](https://modrinth.com/plugin/sertralineitem) or [GitHub Releases](https://github.com/zzzyyylllty/Sertraline-Hydrochloride/releases). Check the project page and release notes for the current build, supported platforms, and service details.

Sertraline is open source, as you might expect. You can fork the project and modify the code according to your preferences.

If you cannot find what you need in the wiki, please join our [Discord](https://discord.gg/VHs958jJXj) or the free QQ group 858827523 for users in China (include Chinese Taiwan) for further support.
