# 简介

你可以使用 Sertraline 创建和管理服务器物品，并通过配置添加名称、描述、属性与动作。

可从 [Modrinth](https://modrinth.com/plugin/sertralineitem) 或 [GitHub Releases](https://github.com/zzzyyylllty/Sertraline-Hydrochloride/releases) 获取插件。遇到手册未解决的问题，可以前往 [Discord](https://discord.gg/VHs958jJXj) 或 QQ 群 858827523 寻求帮助。

Sertraline 开放源代码。你可以查看代码，也可以在自己的分支上调整行为。请在项目页和发行说明中确认当前构建类型、兼容版本与服务安排。[源代码](https://github.com/zzzyyylllty/Sertraline-Hydrochloride)
